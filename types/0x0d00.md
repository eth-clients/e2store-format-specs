# CompressedSignedBlindedBeaconBlock

```
type: [0x0d, 0x00]
data: snappyFramed(ssz(SignedBlindedBeaconBlock))
```

`CompressedSignedBlindedBeaconBlock` entries contain `SignedBlindedBeaconBlock` objects encoded using `SSZ` then compressed using the snappy [framing format](https://github.com/google/snappy/blob/master/framing_format.txt).

A `SignedBlindedBeaconBlock` is a beacon block with the execution payload replaced by the root of the payload, as defined in the [Erc format](../formats/erc.md#blinded-blocks):

```python
class SignedBlindedBeaconBlock(Container):
    message: BlindedBeaconBlock
    signature: BLSSignature
```

The fork - and thus the exact shape of the `BlindedBeaconBlock` - should be derived from the `slot`, as with `CompressedSignedBeaconBlock`.
